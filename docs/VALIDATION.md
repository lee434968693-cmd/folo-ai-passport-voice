# 随身语音验证边界

本次仅拆分仓库和文档，没有改变设备业务代码或 Windows 程序。独立项目不是新的整机固件版本。

在已验证的集成固件 `0.2.0-rc.6` 上，Windows EXE 与实机完成 3 轮按住上键、松开、下键测试：12 个系统注入键事件顺序正确，语音键释放 47–93 ms，Enter 16–47 ms。测试拦截键事件，未向用户当前窗口提交文字。这不是输入法识别准确率测试。

Windows 转发器 15 项单测覆盖 hold/tap、结束释放、残留状态对账、重复 Enter、音频失败回退等。设备纯状态机与界面数学通过 host 测试。新的应用目录再次独立运行这些测试；GitHub Actions 记录对应提交结果。

PC EXE 来自 Python 3.11.8、sounddevice 0.5.6、PyInstaller 6.20.0，源码与本项目 Windows 文件一致；EXE 的 `--help`、`--diagnose` 已检查。

**未验收：** 新电脑从零安装、其他输入法/系统版本、真实字错误率、长时运行、用户自定义宿主的整机编译及音质。本仓库不分发整机 BIN，不宣称这里的模块可直接刷机。

## macOS 直接语音识别模式

2026-10-23 在 Apple 芯片 Mac mini、macOS 27、Python 3.13.17 arm64 上完成：

- Apple Speech 辅助程序通过 Swift 6.4 构建并通过临时签名校验。
- 使用系统 `say` 生成的 16 kHz PCM 测试音频，经真实 Apple Speech 识别得到
  “这是语音输入测试”。
- 将测试音频编码为设备使用的 IMA ADPCM 块，走完整 `MacForwarder` 音频处理路径
  后，识别文字成功粘贴到“文本编辑”。
- 识别辅助程序使用后台启动，不改变当前输入框焦点。
- 32 项 Mac 单元与 UDP 集成测试通过。
- 菜单栏宿主通过本地通知接收识别文字，并以自身辅助功能权限写入当前前台输入框；
  Python 子进程不需要单独获得辅助功能权限。
- 真实 AI Passport 设备已识别并填入“我说话能同步吗？”等中文语音。
- LaunchAgent 可在用户登录后启动菜单栏客户端；父应用退出时子进程会自动结束，
  避免端口残留。

**仍待验收：** 不同 macOS/Apple Speech 语言模型、其他中文输入环境、超长时间
运行、系统升级后的权限迁移，以及公开发布后的全新机器安装。自动测试与测试音频
不能代替这些结果。
